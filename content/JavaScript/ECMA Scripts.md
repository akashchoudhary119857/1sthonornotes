ECMAScript is a standardized scripting language specification developed by Brendan Eich while he was at Netscape. Here’s a brief history:

Creation: Brendan Eich created the language in May 1995. Initially, it was named Mocha, then LiveScript, and finally JavaScript12.
Standardization: In November 1996, Netscape and Sun Microsystems submitted JavaScript to the Ecma International standards organization. The first edition of the ECMAScript standard (ECMA-262) was adopted by the Ecma General Assembly in June 199712.
Evolution: Over the years, ECMAScript has evolved through multiple editions, with significant updates in ES5 (2009), ES6 (2015, also known as ECMAScript 2015 or ES2015), and subsequent yearly updates12.

Types of ECMA scripts and their update features :
### ECMAScript 1 (ES1) - 1997 

- **First edition**: Established the core features of JavaScript.

### ECMAScript 2 (ES2) - 1998

- **Editorial changes**: Aligned the standard with ISO/IEC 16262.

### ECMAScript 3 (ES3) - 1999

- **New features**:
    - Regular expressions
    - Try/catch exception handling
    - Switch statement
    - Do-while loop

### ECMAScript 4 (ES4)

- **Never released**: Due to political differences and complexity.

### ECMAScript 5 (ES5) - 2009

- **New features**:
    - Strict mode
    - JSON support
    - Array methods (e.g., `forEach`, `map`, `filter`)
    - `Object.defineProperty`
    - `Object.create`
    - `Array.isArray`
    - `String.trim`

### ECMAScript 5.1 (ES5.1) - 2011

- **Editorial changes**: Aligned with ISO/IEC 16262:2011.

### ECMAScript 2015 (ES6) - 2015

- **Major updates**:
    - `let` and `const`
    - Arrow functions
    - Classes
    - Template literals
    - Default parameters
    - Destructuring assignment
    - Promises
    - Modules (import/export)
    - Spread and rest operators
    - `Map` and `Set`

### ECMAScript 2016 (ES7) - 2016

- **New features**:
    - Exponentiation operator (`**`)
    - `Array.prototype.includes`

### ECMAScript 2017 (ES8) - 2017

- **New features**:
    - Async functions (`async`/`await`)
    - Object entries (`Object.entries`)
    - Object values (`Object.values`)
    - String padding (`padStart`, `padEnd`)
    - Shared memory and atomics

### ECMAScript 2018 (ES9) - 2018

- **New features**:
    - Asynchronous iteration
    - Rest/spread properties
    - `Promise.prototype.finally`
    - Additions to regular expressions

### ECMAScript 2019 (ES10) - 2019

- **New features**:
    - `Array.prototype.flat` and `flatMap`
    - `Object.fromEntries`
    - String trimming (`trimStart`, `trimEnd`)
    - Optional catch binding

### ECMAScript 2020 (ES11) - 2020

- **New features**:
    - Nullish coalescing operator (`??`)
    - Optional chaining (`?.`)
    - Dynamic import
    - BigInt
    - `Promise.allSettled`
    - `globalThis`

### ECMAScript 2021 (ES12) - 2021

- **New features**:
    - Logical assignment operators (`&&=`, `||=`, `??=`)
    - Numeric separators
    - `String.prototype.replaceAll`
    - WeakRefs and FinalizationRegistry

### ECMAScript 2022 (ES13) - 2022

- **New features**:
    - Class fields
    - `Array.prototype.at`
    - Top-level await
    - `Object.hasOwn`

### ECMAScript 2023 (ES14) - 2023

- **New features**:
    - Array grouping
    - `Array.prototype.toSorted`
    - `Array.prototype.toReversed`
    - `Array.prototype.toSpliced`
    - `Array.prototype.with`

### ECMAScript 2024 (ES15) - 2024

- **New features**:
    - Import assertions
    - `Symbol.prototype.description`
    - `String.prototype.matchAll`
