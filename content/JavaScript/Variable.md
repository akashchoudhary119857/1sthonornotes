   **kebab-case / spinal case**
    Used under various languages as you noticed
     Kebab case, also known as “hyphen case” or “spinal case,” is a naming convention where words are separated by hyphens (`-`) and written in lowercase. For example, `user-name` or `background-color`.

### Common Uses of Kebab Case in Programming:

1. **CSS Class and ID Names**: Kebab case is widely used in CSS for naming classes and IDs.

    ```css
    .main-container {
      background-color: #f0f0f0;
    }
    #header-title {
      font-size: 24px;
    }
    ```

2. **HTML Attributes**: HTML attributes often use kebab case, especially in custom data attributes.
    
    HTML
    
    ```html
    <div data-user-id="12345"></div>
    ```

3. **URLs**: Kebab case is commonly used in URLs to improve readability and SEO.
    
    ```url
    https://example.com/user-profile/settings
    ```
    
4. **JavaScript Frameworks**: Some JavaScript frameworks and libraries, like Vue.js, use kebab case for component names and custom directives.

    ```html
    <my-component></my-component>
    ```

5. **Configuration Files**: Kebab case is sometimes used in configuration files, such as YAML or JSON, to maintain consistency and readability.
    
    ```yaml
    api-endpoint: "https://api.example.com"
    ```
